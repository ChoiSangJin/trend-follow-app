# 말문 설치

1. GitHub Release에서 `Malmun-arm64.apk`를 받습니다. ZIP이나 소스 코드는 설치 파일이 아닙니다.
2. Android 7.0 이상 ARM64 기기에서 APK를 엽니다. Galaxy S23은 지원 기기입니다.
3. 설치 출처 허용이 필요하면 APK를 연 브라우저/파일 앱에 한해서 허용합니다.
4. 앱 목록에서 **말문**을 실행합니다. 기존 **Follow MZ**와는 다른 앱(`com.malmun.app`)이며 삭제 없이 함께 설치할 수 있습니다.

이 파일은 개발용 서명 테스트 APK입니다. 출처 허용 후에도 설치가 안 되면 실패 문구를 확인해야 합니다.
일반 출처 허용과 별개의 Play 프로텍트/기기 보안 차단은 동일한 문제가 아니므로 보안 설정을 일괄 해제하지 마세요.
`SHA256SUMS`로 파일 무결성을 확인할 수 있습니다. 인터넷 연결이 안 되면 마지막 브리핑 또는 대화 연습이 표시됩니다.
