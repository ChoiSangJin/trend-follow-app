# 말문 정식 APK 설치

1. GitHub Release에서 `Malmun-arm64-v8a.apk`를 받습니다. Galaxy S23 등 Android 7.0 이상 ARM64 기기용입니다.
2. APK를 열고 필요한 경우 APK를 연 브라우저 또는 파일 앱의 설치 출처를 허용합니다.
3. 앱 이름은 말문, 앱 ID는 `com.malmun.app`입니다. APK는 등록된 영구 배포 키로 서명한 릴리즈 빌드입니다.

`SHA256SUMS`는 APK 파일 무결성을, `SIGNING.txt`는 공개 서명 인증서 SHA-256과 기존 관리형 테스트 서명과의 일치 여부를 제공합니다. 비밀 서명 키는 포함하지 않습니다.

기존 말문 테스트 APK와 서명이 다르면 Android에서 업데이트 설치를 거부합니다. 기존 앱을 삭제한 후 새로 설치할 수 있지만, 삭제 시 기기에 저장된 개인 목록·보관함·메모도 사라질 수 있습니다. 기록이 필요하면 기존 앱을 삭제하지 마세요. 이 경우 단순한 출처 허용 변경으로 해결되지 않습니다.

이후 같은 정식 키로 서명한 더 높은 버전 코드의 APK는 업데이트 설치할 수 있습니다. 설치가 실패하면 정확한 오류 문구를 확인하고, 기기 보안 설정을 일괄 해제하지 마세요.
